Ajouter une chanson

Suivez les étapes de haut en bas, à votre rythme. Rien n'est publié tant que vous n'avez pas cliqué sur le bouton « Publier la chanson », tout en bas de la page.

  • Les champs marqués obligatoire doivent être remplis. Les autres peuvent attendre : vous pourrez les compléter plus tard avec « Modifier ».
  • Un doute ? Le guide d'administration explique tout en détail.
1

Où publier la chanson ? obligatoire

Cliquez sur la rubrique du site où la chanson doit apparaître. La suite du formulaire s'adapte à votre choix.

Choisissez d'abord une catégorie ci-dessus : les étapes suivantes apparaîtront ensuite.
2

Présentez la chanson

Le titre et l'artiste s'affichent sur la fiche de la chanson.

Écrivez-le normalement : il sera mis en MAJUSCULES automatiquement. Deux chansons ne doivent pas avoir le même titre.
Le nom affiché comme « Interprète » sur la fiche.

La chanson est-elle une exclusivité ?

Répondez Oui seulement si la chanson est sous contrat avec un distributeur (Spotify, Deezer…) : la chanson n'est alors pas vendue sur Créatoké, seul son créatoké l'est. Dans le doute, laissez Non.

La mettre en avant comme « coup de cœur » ?

Oui : elle apparaît dans le carrousel « Nos coups de cœur » de la page d'accueil.

3

Ajoutez les fichiers audio

Cliquez sur une case pour choisir le fichier sur votre ordinateur, ou faites-le glisser dessus. L'envoi démarre tout seul : attendez la coche verte, puis cliquez sur « Écouter » pour vérifier que c'est le bon.

MP3 ou WAV ? Le nom du format est indiqué sur chaque case et à la fin du nom de votre fichier (ex. « ma-chanson.mp3 »). Le MP3 est léger, le WAV est la version haute qualité.

4

Choisissez la pochette facultatif

L'image affichée avec la chanson. Une image carrée rend le mieux. Sans image, une image générique est utilisée.

ou

Pour utiliser l'IA, ajoutez d'abord un fichier audio à l'étape 3 : elle s'en sert pour imaginer l'image.

5

Écrivez les textes

Vous pouvez les écrire vous-même, ou laisser l'IA les proposer à partir du fichier audio. Relisez toujours ce que propose l'IA : elle remplace ce qui était déjà écrit dans la case.

Les boutons « ✨ IA » s'activent dès qu'un fichier audio est ajouté à l'étape 3.

Quelques phrases qui donnent envie d'écouter : le style, l'ambiance, le sujet de la chanson.

Paroles facultatif

Affichées avec le bouton « Voir les paroles » sur la fiche.

Message pour les visiteurs à remplir pour une exclusivité

Comme la chanson est une exclusivité, ce texte remplace ses offres sur la fiche. Exemple : « Cette chanson est disponible sur les plateformes ; vous pouvez acheter son créatoké ci-dessous. »

6

Ajoutez la vidéo ou le titre Spotify facultatif

Copiez le lien depuis YouTube ou Spotify et collez-le simplement ici (clic droit → Coller). Le site s'occupe du reste.

Sur YouTube : bouton Partager sous la vidéo → Copier.
Vidéo reconnue
Ce lien ne ressemble pas à un lien YouTube. Vérifiez-le.
Sur Spotify : clic droit sur le titre → Partager → Copier le lien du titre.
Titre Spotify reconnu
Ce lien ne ressemble pas à un lien Spotify. Vérifiez-le.
7

Fixez les prix

Pour chaque offre, choisissez d'abord si elle est proposée à la vente, puis écrivez son prix en euros. Écrivez 0 pour un téléchargement gratuit.

Chaque offre proposée doit avoir son fichier à l'étape 3, sinon le client paie mais ne reçoit rien.

Annuler

Merci de patienter : un fichier est encore en cours d'envoi. Le bouton redeviendra cliquable tout seul.

Après la publication, vous arrivez sur la liste des chansons. Ouvrez ensuite la fiche pour vérifier l'écoute et les prix.

Copier le lien d'un titre Spotify

  1. Sur Spotify, faites un clic droit sur le titre (ou cliquez sur les trois petits points à côté).
  2. Choisissez Partager, puis Copier le lien du titre.
  3. Revenez ici, faites un clic droit dans la case « Lien du titre Spotify » et choisissez Coller.
  4. Le message vert « Titre Spotify reconnu » apparaît : c'est bon !

Le code d'intégration (« Intégrer le titre ») fonctionne aussi : vous pouvez coller tout le code, le site garde seulement ce qu'il faut.
